# Synthetic conversation vision fixtures

These three 512 × 512 RGB PNGs are authored illustrations generated by
`generate.py`, using Pillow. They contain no source photos, customer content,
identifiers, text labels, or image metadata.

- `dog.png`: a brown dog sitting on grass.
- `person.png`: an adult person wearing a blue sweater outdoors.
- `cat.png`: an orange cat on grass, available as an unrelated distractor.

The distinct subjects let a bounded model evaluation check image selection and
follow-up context. Passing with these illustrations does **not** prove realistic
photo understanding, photorealistic editing quality, or likeness preservation.

Regenerate deterministically with Python and Pillow:

```sh
python3 apps/image-gen/scripts/fixtures/photo-conversation/generate.py
```

Generation is local: no network access, provider calls, or random inputs.
